Budget.jsx
==> Fetch the project budget from the ProjectBudget Database
==> Can update and delete.
==> Automatically calculate the actual cost, variance, and overhead after the labor and material/equipment cost.
==> After selecting a newly created project, clicked the sync budget button to get the budget table but its important to note that you can only clicked it once, if you clicked it again, it will reset the data excluding the estimated budget.

ProjectForm.jsx
==> Create new project, with input fields: Phase Name, Start and End Date, Phase and Its own Task with each start and end date.

DependencySetup.jsx
==> Next page of the ProjectForm.
==> Assign Dependency to each task.
==> Input Total Budget to the project and allocate resource to employees.

Employee.jsx

Overview.jsx
==> Display the Progression, Total budget used, Team size and Day Remaining
==> Display project timeline with button to view gantt chart.

Project.jsx

==> Display the pages of overview, wbs, task dependencies, resource, budget, and report page.
==> With project selector, button to view project list and add new project.

ProjectGantt.jsx

ProjectList.jsx
