# 🚀 Quick Start: Add Your First Inventory Item

## ✅ What You Need to Fill In

### Required Fields (Must Fill):
1. **Item Name**: Product name (e.g., "Laptop Dell XPS 15")
2. **SKU**: Unique code (e.g., "LAP-DELL-XPS15")
   - Only use: letters, numbers, hyphens (-), underscores (_)
   - No spaces or special characters!
3. **Category**: Product type (e.g., "Electronics")
4. **Quantity**: How many in stock (e.g., 25)

### Optional But Recommended:
5. **Price**: Product price (e.g., 1299.99) - Needed for e-commerce!
6. **Image**: Upload product photo - Makes it look professional!
7. **Description**: Product details - Helps customers decide!

---

## 📝 Example: Adding a Laptop

```
✅ Item Name: Dell XPS 15 Laptop
✅ SKU: LAP-DELL-XPS15
✅ Category: Electronics
✅ Quantity: 25
💰 Price: 1299.99
📷 Image: [Upload laptop.jpg]
📄 Description: High-performance laptop with Intel i7, 16GB RAM, 512GB SSD
```

---

## ❌ Common Mistakes

### SKU Errors:
- ❌ "LAP 001" (has space)
- ❌ "LAP@001" (has @)
- ❌ "AB" (too short)
- ✅ "LAP-001" (correct!)
- ✅ "LAP_001" (correct!)

### Other Errors:
- ❌ Leaving Name empty
- ❌ Leaving Category empty
- ❌ Negative quantity
- ❌ Using same SKU twice

---

## 🎯 Step-by-Step

1. Click **"Add Item"** button (green, top right)
2. Fill in the form:
   - Type product name
   - Create unique SKU (use format: CATEGORY-NAME-NUMBER)
   - Select or type category
   - Enter quantity
   - Add price (for e-commerce)
   - Upload image (optional)
   - Add description (optional)
3. Click **"Add Item"** button in modal
4. ✅ Done! Item appears in list and e-commerce store

## 🔧 Troubleshooting

**Can't submit form?**
- Check all required fields are filled (*)
- Make sure SKU has no spaces or special characters
- Verify SKU is at least 3 characters

**Image won't upload?**
- File must be under 5MB
- Use JPG, PNG, GIF, or WebP format
- Make sure backend server is running

**"SKU already exists" error?**
- Each SKU must be unique
- Try adding a number: LAP-001, LAP-002, etc.
